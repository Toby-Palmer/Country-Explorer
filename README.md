# Country-Explorer

## ✨ Features

### 🌎 Country Search
- Search for countries using live API data
- Display key information including:
  - Country name
  - Capital city
  - Region
  - Population

### ⚖️ Country Comparison
- Compare multiple countries side-by-side
- Analyse differences in population and regional information

### 📊 Data Visualisation
- Generate graphical population comparisons
- Present data in a clear and accessible format

### ⭐ Favourite Countries
- Save favourite countries locally
- Persistent storage using file handling

### ❓ Interactive Quiz System
- Test knowledge through dynamically generated questions
- Supports multiple question types:
  - Capital questions
  - Region questions

---

# 🔌 API Integration

This project was originally developed using the REST Countries API to retrieve live country information.

The application was built around the API's v3.1 response structure. Since the API has introduced newer versions and changes to its response format, the API wrapper may require updates to support the latest version.

The project architecture separates API communication from the main application logic, allowing the data source to be updated without requiring major changes to the user interface or core functionality.
